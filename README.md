## دعم المشروع ومشاركته

أُعدّ «أثمان» ابتغاء وجه الله تعالى وخدمةً لكتابه الكريم، ونسأل الله أن ينفع به ويتقبّله. التطبيق مجاني ومتاح للجميع.

مشاركة المشروع مع من يحتاجه، والدعاء لمطوّره، والمساهمة في تحسينه؛ وجوه دعم نعتزّ بها. ولمن رغب واستطاع، تتاح مساندة مالية اختيارية للمطوّر لتشجيعه على مواصلة تطوير مشاريع مجانية ومفتوحة المصدر.

**[زيارة صفحة المشاركة والمساندة الاختيارية](https://elkandoussi1.github.io/athman-quran/support.html)**

## عن أثمان

تطبيق عربي متجاوب لفهرسة أحزاب القرآن الستين وأنصافها الـ120 وأرباعها الـ240 وأثمانها الـ480، وفق التقسيم المغربي للمصحف المحمدي. يتضمن فهرس السور وقراءة النص برواية ورش، والبحث الذي يتجاهل التشكيل، والإشارات المحلية وآخر موضع قراءة ومتابعة المراجعة والوضع الليلي.

التطبيق ثابت داخل `dist/`، دون خدمات خارجية أثناء الاستخدام. يتضمن ملف تعريف PWA وأيقونات الهاتف وزر تثبيت، ويخزّن ملفات القراءة محليًا بعد اكتمال التحميل الأول. يعمل أيضًا عند نشره داخل مسار مستودع GitHub Pages.

## النشر على حسابك في GitHub

1. أنشئ مستودعًا عامًا باسم `athman-quran` على حسابك. يمكن استخدام اسم آخر.
2. ارفع محتويات هذا المشروع إلى الفرع `main`، بما فيها مجلد `.github` وملفات `dist`.
3. افتح **Settings → Pages**، واختر **GitHub Actions** في خانة **Source**.
4. من **Actions** افتح **Deploy Athman to GitHub Pages**، ثم شغّل **Run workflow** إن لم يبدأ تلقائيًا.
5. بعد نجاح النشر، افتح الرابط الذي يعرضه **Settings → Pages → Visit site**.

عند استخدام GitHub Free، اختر مستودعًا عامًا حتى يتوفر GitHub Pages. ملفات المشروع جاهزة للنشر ولا تحتاج إلى تثبيت حزم أو تشغيل عملية بناء. يجري مسار النشر اختبارات القرآن وملفات التطبيق قبل النشر.

## التثبيت على الهاتف

- أندرويد: افتح **رابط GitHub Pages المنشور** في Chrome، ثم اضغط زر «تثبيت التطبيق» داخل أثمان، أو افتح قائمة Chrome واختر «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».
- iPhone وiPad: افتح الرابط في Safari، ثم **مشاركة → إضافة إلى الشاشة الرئيسية**.
- يظهر التطبيق بأيقونته الخاصة، ويطلب التطبيق تثبيته فقط عندما تضغط زر التثبيت. تختلف طريقة العرض بحسب المتصفح والهاتف.
- انتظر اكتمال تنزيل ملفات القراءة قبل الاعتماد على القراءة دون اتصال.

هذه النسخة تطبيق ويب قابل للتثبيت (PWA). يمكن استخدام رابط GitHub Pages المنشور أيضًا مع أداة تغليف تطبيقات تدعم روابط المواقع، مثل PWABuilder، لإعداد حزمة أندرويد بحسب متطلبات تلك الأداة. ملف APK ليس مرفقًا بهذا المشروع.

## التحديث

يعتمد النشر على محتويات مجلد `dist/` في الفرع `main` مباشرةً. عند الانتقال من النسخة الأولى التي كانت تُنشر من حزمة مضغوطة، استبدل ملف `.github/workflows/pages.yml` بالملف المرفق مع هذا التحديث، وارفع ملفات `dist/` المحدثة. بعد ذلك تنشر التعديلات تلقائيًا.

ادفع التغييرات إلى `main`؛ ينشر مسار GitHub Pages النسخة الجديدة تلقائيًا. يتصل التطبيق لجلب أحدث ملفاته عند الفتح، مع الاحتفاظ بنسخة محلية للقراءة دون اتصال. إذا أضفت ملفًا ضروريًا للقراءة، أضفه إلى قائمة `FILES` في `dist/sw.js` وحدّث رقم نسخته.

الإشارات والمراجعات محفوظة في متصفحك. الانتقال من رابط استضافة مختلف إلى GitHub Pages يبدأ بمساحة تخزين محلية جديدة لهذا الرابط.

## التحقق

`node --check dist/assets/app.js`

`python validate.py`

`node test-divisions.cjs`

`node test-pwa.cjs`

لا توجد تبعيات بناء. يُخدم مجلد `dist` كما هو.

اشتُقت الأنصاف من كل أربعة أثمان متتابعة، والأرباع من كل ثمنين متتابعين. يحتفظ التطبيق بالإشارات السابقة؛ وتُحسب مراجعة النصف والربع من الأثمان نفسها. للتحقق من حدود التقسيمات وتزامن المراجعة: `node test-divisions.cjs`.
