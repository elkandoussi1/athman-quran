## عن أثمان

تطبيق عربي متجاوب لفهرسة أحزاب القرآن الستين وأنصافها الـ120 وأرباعها الـ240 وأثمانها الـ480، وفق التقسيم المغربي للمصحف المحمدي. يتضمن فهرس السور وقراءة النص برواية ورش، والبحث الذي يتجاهل التشكيل، والإشارات المحلية وآخر موضع قراءة ومتابعة المراجعة والوضع الليلي.

التطبيق ثابت داخل `dist/`، وتعمل الفهارس والقراءة محليًا دون خدمة خارجية. يتضمن ملف تعريف PWA وأيقونات الهاتف وزر تثبيت، ويخزّن ملفات القراءة محليًا بعد اكتمال التحميل الأول. يعمل أيضًا عند نشره داخل مسار مستودع GitHub Pages. التسميع الصوتي التجريبي يعتمد على خدمة التعرّف التي يوفرها المتصفح، وقد يحتاج إلى الإنترنت.

## التسميع وإخفاء الآيات

افتح ثمنًا أو ربعًا أو نصفًا أو سورة؛ تظهر صفحة المصحف مباشرةً بالنص كاملًا. يبدأ الميكروفون عند الضغط عليه والموافقة على إذن المتصفح. ويمكن بدء التسميع من زر الميكروفون في الشريط العلوي للصفحة الرئيسية.

عند تشغيل الميكروفون، يبحث التطبيق في نص القرآن كاملًا عن الكلمات التي تقرؤها، بما فيها البداية من وسط آية. ينتقل إلى الثمن أو الربع أو النصف أو السورة المطابقة بحسب نوع القراءة المفتوح، ويواصل بين المقاطع دون إعادة فتح الميكروفون. الآيات والعبارات المتكررة تحتاج كلمات إضافية لتمييز الموضع؛ لا يُختار موضع عشوائي عند تشابه النتائج. قد تُعرض معاينة لموضع مرجّح بعد نتيجتين أوليتين متوافقتين، لكن لا تُعتمد الكلمات ولا الأخطاء قبل النتيجة الصوتية النهائية.

إذا قرأت كلمات صحيحة بعد كلمة مستبدلة أو محذوفة، يتابع التطبيق من الكلمات المطابقة ويظلّل مواضع التعثر بالأحمر. لا تُحتسب الكلمات المتجاوزة صحيحة، ولا يُحتسب ما قبل موضع بدء قراءتك تسميعًا. إذا لم تصل كلمات كافية لاستعادة المزامنة يبقى الموضع الحالي؛ يمكنك تصحيحه أو متابعة القراءة، وتظهر الكلمة المساعدة بعد 3 محاولات غير متطابقة. يبقى تقييم المراجعة اليدوي «تمت المراجعة» منفصلًا عن المتابعة الصوتية.

يُخفى النص افتراضيًا عند بدء التسميع، وتظهر الكلمات المؤكدة مع تقدّم القراءة. يمكن إلغاء «إخفاء النص عند بدء التسميع» من الإعدادات، أو تبديل الإظهار من زر العين. إخفاء النص والتلميحات والتظليل لا تغيّر مواضع الكلمات أو المسافات. زر الكتاب يفتح الفهرس، وزر الهدية يفتح الدعم والمشاركة. تضم الإعدادات المظهر الفاتح وحجم الخط وكتم التنبيه والمتابعة اليدوية، ويمكن حفظ تحديدات القلم محليًا ومسح تحديدات المقطع.

هذه أداة تجريبية لمطابقة الكلمات الملتقطة، وليست تقييمًا للتجويد أو مخارج الحروف أو أوجه رواية ورش. قد يخطئ التعرّف الصوتي فيُظلّل كلمة قُرئت صحيحًا أو يتأخر تحديد الموضع. تعتمد سرعة الاستجابة على خدمة المتصفح والاتصال؛ الفهرسة والبحث والمطابقة نفسها تعمل محليًا. النص والخط الأصليان لرواية ورش محفوظان، ولا تتضمن النسخة بيانات تلوين التجويد المعتمدة أو خريطة صفحات مطبوعة مطابقة.

لا يُرسل الصوت إلى خادم يملكه أثمان، ولا تُحفظ تسجيلات أو نصوص صوتية في التخزين المحلي. قد يعالج مزوّد خدمة المتصفح الصوت عبر الإنترنت وفق إعداداته. انقطاع الشبكة أو رفض إذن الميكروفون أو عدم سماع صوت لا يُحتسب محاولة خاطئة، ويتوقف الميكروفون عند إغلاق القارئ أو مغادرة الصفحة. إن لم يدعم المتصفح التعرّف الصوتي، تبقى القراءة والتلميحات والمتابعة اليدوية متاحة.

## الجلسات ومواضع المراجعة

افتح **جلساتي ومواضع المراجعة** من القائمة الجانبية أو قائمة المصحف. يُحفظ السجل عند إيقاف الميكروفون بعد التقاط كلمات، ويحتفظ بآخر 100 جلسة على جهازك. تتضمن الجلسة مراجع الآيات والكلمات وعدّ الكلمات المطابقة ومدة الجلسة وعلامات المراجعة؛ لا تتضمن صوتًا أو نص التعرف الملتقط. الزمن هو وقت الجلسة ويشمل الوقفات أثناء تشغيل الاستماع.

يمكن فتح الموضع من السجل، وإزالة علامة غير صحيحة، وتحديد هدف يومي للدقائق، وتنزيل نسخة من السجل أو استيرادها مع الدمج. تبقى إشارات المصحف وحالة «تمت المراجعة» اليدوية محفوظة بمفاتيحها السابقة.

تتيح إعدادات القارئ **تسميعًا حرًا** أو **مراجعة المقطع المفتوح فقط** أو **قراءة**، وخيار التوقف حتى تصحيح الكلمة أو المتابعة بعد التعثر. يمكن إظهار المطابقة كلمةً كلمةً أو بعد اكتمال الآية. الضغط على كلمة يفتح خياراتها: إزالة علامة غير صحيحة إن وجدت، والمتابعة من الكلمة، والبحث عن مواضع العبارة في القرآن. البحث داخل القارئ يشمل القرآن كله ويقبل مرجعًا مثل `29:46` بترقيم ورش.

[مراجعة الملف المرجعي والفروق وحدود التكافؤ](docs/APK_REFERENCE_REVIEW.md) توضّح ما فُحص من APK وما نُفّذ فعليًا، وما يحتاج خدمات أو مصادر إضافية. لم تُنسخ أصول التطبيق المرجعي أو شفرته إلى أثمان، ولا يُدّعى تكافؤ محرك المتصفح مع نموذج ترتيل الصوتي الخاص.

## النشر على حسابك في GitHub

1. أنشئ مستودعًا عامًا باسم `athman-quran` على حسابك. يمكن استخدام اسم آخر.
2. ارفع محتويات هذا المشروع إلى الفرع `main`، بما فيها مجلد `.github` وملفات `dist`.
3. افتح **Settings → Pages**، واختر **GitHub Actions** في خانة **Source**.
4. من **Actions** افتح **Deploy Athman to GitHub Pages**، ثم شغّل **Run workflow** إن لم يبدأ تلقائيًا.
5. بعد نجاح النشر، افتح الرابط الذي يعرضه **Settings → Pages → Visit site**.

عند استخدام GitHub Free، اختر مستودعًا عامًا حتى يتوفر GitHub Pages. ملفات المشروع جاهزة للنشر ولا تحتاج إلى تثبيت حزم أو تشغيل عملية بناء. يجري مسار النشر اختبارات القرآن وملفات التطبيق قبل النشر.

## التثبيت على الهاتف

- أندرويد: افتح **رابط GitHub Pages المنشور** في Chrome، ثم اضغط زر «تثبيت التطبيق» داخل أثمان، أو افتح قائمة Chrome واختر «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».
- iPhone وiPad: افتح الرابط في Safari، ثم **مشاركة → إضافة إلى الشاشة الرئيسية**.
- يظهر التطبيق بأيقونته الخاصة، ويطلب التطبيق تثبيته فقط عندما تضغط زر التثبيت. تختلف طريقة العرض بحسب المتصفح والهاتف.
- انتظر اكتمال تنزيل ملفات القراءة قبل الاعتماد على القراءة دون اتصال.

هذه النسخة تطبيق ويب قابل للتثبيت (PWA). يمكن استخدام رابط GitHub Pages المنشور أيضًا مع أداة تغليف تطبيقات تدعم روابط المواقع، مثل PWABuilder، لإعداد حزمة أندرويد بحسب متطلبات تلك الأداة. ملف APK ليس مرفقًا بهذا المشروع.

## التحديث

يعتمد النشر على محتويات مجلد `dist/` في الفرع `main` مباشرةً. عند الانتقال من النسخة الأولى التي كانت تُنشر من حزمة مضغوطة، استبدل ملف `.github/workflows/pages.yml` بالملف المرفق مع هذا التحديث، وارفع ملفات `dist/` المحدثة. بعد ذلك تنشر التعديلات تلقائيًا.

ادفع التغييرات إلى `main`؛ ينشر مسار GitHub Pages النسخة الجديدة تلقائيًا. يتصل التطبيق لجلب أحدث ملفاته عند الفتح، مع الاحتفاظ بنسخة محلية للقراءة دون اتصال. إذا أضفت ملفًا ضروريًا للقراءة، أضفه إلى قائمة `FILES` في `dist/sw.js` وحدّث رقم نسخته.

الإشارات والمراجعات محفوظة في متصفحك. الانتقال من رابط استضافة مختلف إلى GitHub Pages يبدأ بمساحة تخزين محلية جديدة لهذا الرابط.
